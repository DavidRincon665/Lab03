## Resumen

Cronómetro con Timers:
Se desarrolló un cronómetro que utiliza temporizadores (timers) para llevar el seguimiento del tiempo.
El cronómetro muestra la hora en el formato estándar de HH:mm

El sistema permite configurar una alarma que se activa después de un tiempo predefinido. Por ejemplo, si se configuran 2 minutos, al transcurrir dicho tiempo, se activa una alarma que suena cada 10 segundos.
Animación con Temporizador:
Se programó un temporizador que muestra secuencialmente imágenes almacenadas en un arreglo, permitiendo la creación de una animación en pantalla.
El usuario tiene la opción de controlar la velocidad de la animación mediante un control deslizante (slider), ajustando la frecuencia con la que se muestra cada imagen.

*Palabras clave:* Cronómetro, temporizador, HH:mm
, alarma, secuencia de imágenes, animación, control deslizante, slider, velocidad de animación.

## Introducción

En este informe se describe el desarrollo de dos funcionalidades clave empleando temporizadores en un entorno de programación: un cronómetro que muestra el tiempo en formato HH:mm
y permite configurar alarmas, y una animación controlada mediante un temporizador que permite al usuario ajustar la velocidad de visualización de imágenes mediante un control deslizante. Ambas aplicaciones destacan el uso de temporizadores como herramientas eficientes para gestionar tareas basadas en tiempo y mejorar la interacción del usuario.

## Marco Teórico

Los temporizadores son objetos de la clase Timer que se utiliza para programar una tarea que se ejecutará después de un período de tiempo específico. Las tareas se pueden programar para una ejecución única o para una ejecución repetida periódicamente.

Se pueden crear varios objetos de la clase Timer, pero hay un único hilo en segundo plano que supervisa la ejecución de las tareas de cada Timer.

El desarrollo se documenta en las siguientes secciones, junto con ejemplos y pseudocódigo:

## Análisis de Resultados

El cronómetro implementado mostró precisión en el formato HH:mm
y permitió configurar alarmas, activándose correctamente tras el tiempo programado. El desempeño fue adecuado, con posibles mejoras en la interfaz de usuario y opciones de alerta.

La animación con temporizador permitió cambiar la velocidad de visualización mediante un control deslizante, con buen rendimiento en general, aunque mostró pequeñas caídas a velocidades muy altas. Se sugiere optimizar el sistema y agregar más controles de usuario.
## Conclusiones
